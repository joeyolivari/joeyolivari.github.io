AVISO DE PRIVACIDAD

Cómo se gestionan tus datos

En resumen: el sitio no tiene una base de datos de clientes. Las consultas se envían mediante un servicio externo de formularios y uso tus datos para responderte.

Este sitio web

El sitio consta de páginas estáticas alojadas en GitHub Pages. No tiene scripts propios de seguimiento, analítica, cookies ni base de datos. Al enviar el formulario, tus datos llegan a FormSubmit, un servicio externo que procesa la consulta y la reenvía a mi correo. FormSubmit puede aplicar filtros de spam y conservar información según sus políticas de privacidad. No incluyas datos personales o financieros sensibles. GitHub puede conservar registros estándar del servidor.

Idioma y almacenamiento temporal del formulario

La preferencia de idioma se guarda localmente en tu navegador. Si cambias entre inglés y español durante una solicitud, el borrador se conserva temporalmente en el almacenamiento de la sesión del navegador para transferirlo a la página del otro idioma y se elimina inmediatamente después de restaurarlo. El borrador no se me envía hasta que seleccionas Enviar consulta.

Qué hago con tus datos

  • Uso tu nombre, correo y consulta únicamente para responderte y, si decides continuar, entregar el proyecto.
  • No vendo tus datos ni te añado a listas de correo. Las consultas se comparten con FormSubmit únicamente para su procesamiento y entrega.
  • Los archivos que envíes se guardan solo en una carpeta del proyecto y se eliminan 14 días después de la entrega, salvo que solicites conservarlos más tiempo.
  • Si trabajamos mediante Fiverr o Upwork, también se aplican las condiciones y políticas de privacidad de esa plataforma.

No envíes

Contraseñas, credenciales, números de seguro social, cuentas bancarias o tarjetas, o datos personales de clientes o empleados que no sean necesarios. Oculta o elimina esas columnas antes de compartir archivos.

Consultas o solicitudes de eliminación

Escribe a joeyolivari@gmail.com y responderé o eliminaré tus datos.
