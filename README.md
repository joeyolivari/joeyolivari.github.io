# Joey Olivari — Reporting & Excel Services

Clear Excel reports, budget vs actual trackers and practical reporting tools for small businesses, plus a portfolio of larger data projects.

Website: https://joeyolivari.github.io/

## Pages

- `index.html` — services-first home page
- `services.html` — both services, pricing guidance, downloadable samples, FAQ and inquiry form
- `career-tools.html` — resume rewrite service
- `privacy.html` — privacy note
- `ai-command-center.html`, `sql-quest.html` — case studies

The inquiry form has no backend: it opens a pre-filled email in the visitor's own mail app. Sample workbooks in `assets/samples/` use fictional data only.

## Deploy

Static HTML, CSS and JavaScript. GitHub Pages publishes from the `main` branch, root folder. To redeploy, merge changes into `main` and push; Pages rebuilds within a few minutes.
