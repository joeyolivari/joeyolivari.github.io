The learning question

SQL exercises can teach syntax without showing why a query matters. Financial operations provide concrete questions: which clients need a KYC review, which transactions deserve investigation, and which records fail reconciliation?

This project asks: Can those scenarios make query practice more purposeful and easier to explore?

Scope and approach

SQL Quest is an independent browser-based learning project. It combines synthetic financial records, investigation missions, a learning center, and a free-practice SQL lab.

  • Provide a reason to query: missions frame a task around client documentation, transaction monitoring, reconciliation, or audit readiness.
  • Let learners experiment: an in-browser SQLite engine executes queries and returns results or errors.
  • Support practice: lessons, hints, and skill tracking sit alongside a sandbox with a visible schema.
  • Keep the entry point simple: the static browser application needs no user-operated database server; a service worker supports offline use.

Three decisions behind the experience

Use synthetic financial data.

Fictional clients, accounts, and transactions provide domain context without exposing customer information. The scenarios are learning material, not actual compliance cases.

Run SQL inside the browser.

sql.js brings SQLite to WebAssembly, letting a learner inspect a schema and run a query in the same experience. This reduces setup for an introductory practice session.

Offer both missions and free practice.

Structured investigations give a learner a goal. The Training Lab gives them room to try variations, inspect errors, and explore beyond a single expected answer.

What you can try

The deliverable is a playable SQL learning experience with financial scenario tracks, lessons, hints, and a practice lab.

Try this review path: open a beginner mission, inspect the schema, run a query, and compare the returned records with the investigation question. Then try a variation in the Training Lab.

Limitations and next validation

This is a learning tool with synthetic records. It does not validate a real compliance decision, and no measured improvement in learner outcomes is claimed.

A useful next validation would observe new learners completing a mission: where do they misunderstand the schema, the task, or the query feedback? The source is available for review under the repository’s stated license.
